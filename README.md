# Артефакты

- **[Чек-лист](./checklist.md)** — проверки по основным модулям сайта: от авторизации до завершения заказа (`55` проверок).
- **[Тест-кейсы](./test-cases.md)** — примеры детальных сценариев (негативный, граничные значения, сквозной E2E):
  - `TC-CART-01` — Оформление заказа при пустой корзине
  - `TC-CHECKOUT-01` — Проверка верхних граничных значений поля `Zip/Postal Code`
  - `TC-E2E-01` — Успешное сквозное оформление заказа
- **Баг-репорты:**
  - **[BR-01](./BR-01.md)** — Выход текста за границы карточки товара при длинном названии или описании (`Minor / Medium`)
  - **[BR-02](./BR-02.md)** — Отсутствует блокировка оформления заказа при пустой корзине (`Medium / High`)
  - **[BR-03](./BR-03.md)** — Отсутствует валидация формата и длины полей на шаге `Checkout: Your Information` (`Medium / Medium`)
