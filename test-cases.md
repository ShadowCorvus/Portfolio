## TC-CHECKOUT-01: Проверка верхних граничных значений поля Zip/Postal Code

- **ID:** TC-CHECKOUT-01
- **Приоритет:** Medium
- **Предусловие:** Выполнен вход под пользователем `standard_user` / `secret_sauce`, товар добавлен в корзину, открыта страница `/checkout-step-one.html`, поля `First Name` и `Last Name` заполнены валидными данными (`Alexey`, `Bobrov`).

**Шаги:**
1. Ввести в поле `Zip/Postal Code` строку длиной `255` цифр.
2. Нажать кнопку `Continue`.
3. Вернуться на шаг заполнения данных (`/checkout-step-one.html`) и заново заполнить поля `First Name` и `Last Name` валидными данными (`Alexey`, `Bobrov`).
4. Ввести в поле `Zip/Postal Code` строку длиной `256` цифр.
5. Нажать кнопку `Continue`.

**Ожидаемый результат:**  
- При вводе строки из `255` символов система пропускает пользователя на следующий этап оформления заказа (`/checkout-step-two.html`).  
- При вводе строки из `256` символов (превышение граничного значения) система выводит сообщение об ошибке превышения допустимой длины поля и не пропускает пользователя дальше.

---

### Результат выполнения (21.10.2026)
- **Фактический результат:**
  - При вводе `255` символов — переход на `/checkout-step-two.html` выполнен успешно (соответствует ожиданию).
  - При вводе `256` символов — система также пропускает пользователя на `/checkout-step-two.html`, сообщение об ошибке не выводится (не соответствует ожиданию).
- **Статус:** ❌ Failed
- **Связанные дефекты:** [BR-03](./BR-03.md)

## TC-E2E-01: Успешное сквозное оформление заказа

- **ID:** TC-E2E-01
- **Приоритет:** High
- **Предусловие:** Кэш и cookies браузера очищены, открыта страница авторизации (`https://www.saucedemo.com`).

**Шаги:**
1. Ввести `standard_user` / `secret_sauce` и нажать кнопку `Login`.
2. Добавить любой товар в корзину, нажав кнопку `Add to cart` на карточке товара.
3. Нажать на иконку корзины в правом верхнем углу.
4. Нажать кнопку `Checkout`.
5. Ввести валидные данные (`Alexey`, `Bobrov`, `20504-4313`) в поля `First Name`, `Last Name`, `Zip/Postal Code` и нажать кнопку `Continue`.
6. Сверить выбранный товар и итоговую сумму на странице обзора заказа, затем нажать кнопку `Finish`.
7. Нажать кнопку `Back Home`.

**Ожидаемый результат:**  
Вход в аккаунт выполнен успешно, выбранный товар добавляется в корзину. Клик по иконке корзины открывает `/cart.html`, кнопка `Checkout` перенаправляет на `/checkout-step-one.html`, кнопка `Continue` при валидных данных ведёт на `/checkout-step-two.html` с корректным составом и суммой заказа. Кнопка `Finish` переводит на страницу подтверждения заказа (`/checkout-complete.html`) с текстом `Thank you for your order!`, при этом корзина очищается. Кнопка `Back Home` возвращает пользователя в основной каталог (`/inventory.html`).

- **Фактический результат:** Все проверки пройдены успешно, фактическое поведение соответствует ожидаемому.
