# BR-02: Отсутствует блокировка оформления заказа при пустой корзине

- **ID:** BR-02
- **Severity:** Medium
- **Priority:** High
- **Окружение:** ОС Microsoft Windows 10 Pro (10.0.19045, сборка 19045), браузер Mozilla Firefox 157.0 (64-разрядный), разрешение 1920×1080 (100%)
- **Предусловие:** Выполнен вход под пользователем `standard_user` / `secret_sauce`, корзина пуста.

## Шаги воспроизведения
1. Перейти на страницу корзины (`https://www.saucedemo.com/cart.html`).
2. Нажать кнопку `Checkout` при отсутствии товаров в корзине.

## Ожидаемый результат
Кнопка `Checkout` неактивна при пустой корзине либо система выводит уведомление о невозможности оформить пустой заказ, не пропуская пользователя на следующий этап.

## Фактический результат
Пользователь беспрепятственно переходит на шаг заполнения данных `/checkout-step-one.html` и может завершить оформление заказа.
